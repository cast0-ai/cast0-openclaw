# cast0 OpenClaw Plugin

OpenClaw plugin that lets agents create podcast episodes via the cast0 REST API. Published to ClawHub as `@cast0/openclaw-plugin-cast0`.

## Commands

```bash
npm install       # install deps
npm run build     # compile index.ts to dist/
```

## Publishing

When ready to publish, run:

```bash
npm pack
```

This produces a `.tgz` file. Human should upload it manually to ClawHub at clawhub.dev.
